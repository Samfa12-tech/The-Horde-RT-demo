# Horde Lantern RT 1.8.0 draft release notes

- Package version: `1.8.0`
- Android version code: `12`

Follow the road from the lookout into Bellwether. Help Kit reach the tavern,
then return to the square and use the lanes to reach the church, gardens,
mill and riverside. A tavern rest, the record keeper's reading and local
services give you reasons to return as you prepare for the next expedition.

The paths, signs and village landmarks mark where you can go. Keep track of
the errands you have earned in Bellwether Directions. The town's five
residents use their authored dialogue, with archived voice recordings where
included and captions for lines without a recording.

The Windows and Android game builds use Vulkan hardware ray tracing and keep
the standard campaign save locations. The package and playtest receipts
record validation for each build.
