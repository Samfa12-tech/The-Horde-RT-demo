## Keeper source gaps and implementation design

Source inspection confirms current `LichEncounter` has only Dormant, MaintainingRange, Charging, Recovering, Dead. Dormant starts MaintainingRange immediately on finale-zone activation; leaving the finale resets a living lich to Dormant and phase time zero. This would restart a naive reveal added inside the current activation branch. `GameSimulation::UpdateEncounters` also resets the lich when enemy selection changes; selection is retained across Outside seams but switches back to skeleton on earlier route zones. Encounter persistence therefore needs an explicit once-per-attempt rule through retreat/reentry, rather than using selection changes as resets.

Current base root is `(-32.2,-0.77,-13.1)`; active hover amplitude is 0.06 m. Do not delay or accelerate either progression through an audio callback.
