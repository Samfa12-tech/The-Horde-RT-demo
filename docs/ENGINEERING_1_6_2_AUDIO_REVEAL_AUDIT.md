## Android waterfall prevention checkpoint

This prevents a possible backend restart gap; no audible gap, hardware underrun or actual cause has been reproduced. Windows retains its original persistent XAudio2 full-buffer loop. Original waterfall PCM statistics and provenance above remain applicable to that unchanged source.

The pinned Pocket Audio Core `534a6e6811ce653efd5422138c5772b967263ed0` decoder admits only stereo PCM16 48 kHz and at most 576,000 frames (12 s). The existing 21.323479 s mono file cannot pass that API. Runtime header manipulation, local decoder/cursor forks and a Core pin change were rejected. An excessive or unavailable platform minimum fails with diagnostics rather than silently shrinking the queue. These are explicit bounds, not a measured device-memory/latency claim.

`AmbienceOutputQueue` tracks Core-generated, device-accepted and consumed frames separately and holds a single partial block across zero/short writes.
