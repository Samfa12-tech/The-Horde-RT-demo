# Static geometry query and origin contract r02

Scope: prove whether detailed forest triangles can be excluded while the player remains in the tomb after claiming the lantern. This is a corrected source contract for High/Mobile and both hardware RT backends, not an admission certificate. It corrects r01's fifth (legacy room-two) aperture and includes primary-path indoor-dust and mist source-visibility queries plus terminal dielectric receiver lighting.

## Shared query implementation

Both launchers include the same frame shader (`shaders/raytracing/minimal.rgen:7`, `minimal.comp:15`, each includes `include/rt_frame.glsl`). Thus pipeline and RayQueryCompute use the same query helper call sites. High/Mobile also share the code; interface and area-sample budgets change query count, not static visibility (`rt_dielectric_transport.glsl:1-10, 60-63`; `rt_lighting.glsl:72-82, 188-194, 632-639`). Current TLAS world instance mask is `0x01` (`src/vulkan/raytracing/PresentableTinyRtScene.cpp:5150, 6842`).

`traceScene` initializes a TLAS hardware ray query with caller mask and `[tMin,tMax]` (`rt_hit_decode.glsl:387-423`). It uses opaque flags unless water or player-face candidate filtering is enabled; then it uses `gl_RayFlagsNoOpaqueEXT`, inspects triangle candidates, and confirms survivors (`:418-460`). Primary static forest geometry remains an opaque candidate. Shadow mask `0x35` includes world bit 0 and player/roof casters. Opaque-fast visibility uses `NoOpaque`, tMin `0.0015`, tMax `max(segmentDistance, 0.004)`, and filters only clear-glass/water world panes (`rt_lighting.glsl:857-879`). Generic bounded shadow traversal initializes candidate queries with tMin `max(minimumDistance, 0.000001)` and finite tMax; its first segment minimum is `0.0015`, later segments use the dielectric epsilon policy (`:119-122, 184-227`). The straight ordered shadow path uses tMin `0.000001` and finite tMax, chooses opaque or `NoOpaque` from transparent-world segment bounds, and filters water/glass candidates (`:650-714`). Static opaque geometry blocks both modes.
