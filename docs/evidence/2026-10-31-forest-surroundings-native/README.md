  ground-footprint sweep in both directions, with a conservative0.75m body and
  0.22m radius at 0.10m edge intervals. 69 runs need no fence; 127 use visible fences.
  These finite sampled CPU checks are **not a complete gameplay/navigation proof**.

  Earlier full-face preparation exceeded that limit and was rejected.

  exact restoration, **not ray-contributor irrelevance**. Independent native
