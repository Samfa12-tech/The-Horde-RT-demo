# Independent region-page integration checkpoint

The reusable residency scheduler now drives an actual independent V/I/private
primitive/opaque-BLAS owner through ordinary location-based retirement and return
preparation in a **private, opt-in Windows candidate**. Default production and
Android rendering stay on the previously measured combined-owner path. This is
a tested engine integration slice, not completed chapter/phone admission.

## What loads and retires

The existing contributor-safe selection contains84,219 distant forest triangles.
Its compact vertex/index/primitive buffers and BLAS are physically freed after
the page has been removed from a fresh TLAS and that graphics work has completed.
The same immutable CPU payload is uploaded and rebuilt before return/ascent.
The root, coarse terrain, distant town, shared18-layer textures/materials,
collision, actor/held domains and uncertain secondary-ray contributors remain
resident. This proves GPU loading from a cached CPU source; package I/O and CPU
cache eviction are still open. No whole-tomb-unloading claim is made.

The shared scheduler supplies generation tokens, dependencies, required-return
priority, location/prediction/hysteresis and measured/reserved cost accounting.
The chapter adapter retains its all-query absence certificate and simulation
lease. Unknown contributors stay pinned. The private measured profile has one
available detail owner, a0.25s retirement delay and no invented memory-pressure
target. Copies remain bounded at256KiB per application turn; allocation/driver
latency itself is not time-bounded.

Adoption requires complete GPU preparation and current-frame reference proof.
Retirement retains every old page resource through the TLAS update's completed
frame, checks even mask-zero stored references, then destroys the owner exactly
once. Source/request generations, submission/cancellation/quarantine and external
device-idle teardown are preserved. A recoverable Begin/Advance failure resets
both logical and GPU requests and allows one later-turn retry. A second failure
is explicit; unproved GPU work never retries or frees itself.
