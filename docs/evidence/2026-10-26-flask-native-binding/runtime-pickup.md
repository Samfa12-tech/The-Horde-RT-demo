  waystone, native flask and final terrain/contact. Its receipt requires real
  current scene readiness and the one flask BLAS; CPU import alone returns no
  ready site. Move transfers the cache, Destroy/load clears it, and recreation
  retains only the explicit asset configuration.
- The existing owner-thread world adapter republishes current item readiness
  even after zones are Ready. World generation and resource floors reject stale
  replies. Withdrawal immediately removes snapshot presentation/interaction;
  it retains the bound geometry identity so a replacement cannot silently move
  the item inside one world generation. Readiness never grants entitlement.
- Visibility does not require an already-complete static profile: an active
  world item requests the existing complete-contributor restoration before it
  may present. Eligibility still requires ready terrain and no active lease.
  This avoids a readiness/restoration cycle; it is not a new omission proof.
- A fresh existing Interact checks actual F03 reach(1.5m), current input facing,
  grounded support and solid obstruction. Rope owns the action first. Guards,
  attack/dodge, drink/Rest/hand return, speech, pause/death, load, capture and
  unready terrain reject. Looking away in the same publication uses its current
  coherent yaw, not the previous tick. Rejected edges never replay later.
- Pickup changes only the existing one-time capacity entitlement. Health and
  current charges stay exact; only a later eligible Rest fills slot3. No extra
  hand/light ownership, automatic pickup, quest, save schema, transient timer,
  eager saved-boundary rewrite or global cross-slot grant is introduced.
- Existing canonical earned-save capture and exact transactional load retain
  resources. Loading an upgraded record keeps the world item absent; loading
  an older unupgraded record legitimately restores it after fresh readiness.
- World physical30 and carried29 share immutable metadata29/mesh/material/BLAS.
  Snapshot adaptation validates world/resource/rigid-placement coherence before
  publishing either new field. World removal cannot hide the in-use hand.
