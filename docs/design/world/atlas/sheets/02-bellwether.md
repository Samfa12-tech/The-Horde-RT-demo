# 02 / Bellwether / terrain, use, river and mill

[← Regional overview and local sheet index](../README.md) · [Offline viewer](../atlas.html#02-bellwether)

**Overview key 02**. Terrain and use sheets share X −85…92, Y −78…116 m; north up; terrain contours 2 m; 40 m scale bars. The river/mill sheet is a set of profiles and an unfolded diagram, not a third plan footprint. The true mill section on the use sheet is at world Y=13 m, X=25…90 m. Well (0,0,20); mill floor Z16; lake datum Z0. Optional mill bridge is separate from the Foundry crossing.

Exact registration refers to the draft coordinate model. Metric geometry remains proposed and unaccepted in runtime. [Coordinate evidence](../coordinate-evidence.json).
