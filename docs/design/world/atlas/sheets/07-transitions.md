# 07 / Crossings / complications and transitions

[← Regional overview and local sheet index](../README.md) · [Offline viewer](../atlas.html#07-transitions)

**Overview key 07**. An Abbey crossing distance/Z profile plus text keyed to A1–A3, X0/X1/X2–F0, and G0–GC01. No independent north, plan scale or footprint. Use sheet 06 to place these references; the profile uses metric distance along the authored crossing centreline.

Exact registration refers to the draft coordinate model. Metric geometry remains proposed and unaccepted in runtime. [Coordinate evidence](../coordinate-evidence.json).
