# Rope mist-shadow interval prototype — bounded Windows result

The prototype discovers the thin opaque rope intervals through an additional **hardware Vulkan BVH**, then applies their union coverage to the original mist density cells. The measured frozen-view subset passes discovery and weighted-strength checks. The detached full-segment band disappears while nonzero shadow coverage remains at the continuation witnesses. The surface-only image, including the accepted floor shadow, is byte-identical before mist composition.

**Do not integrate this prototype.** Every candidate variant exceeds the unchanged production limits, and the extra acceleration structure/descriptors are an explicit diagnostic ABI extension. Dynamic rope updates, complete scene/material/source admission, Android, QueryCompute and owner visual acceptance remain unproved. This checkpoint publishes evidence and reproduction recipes only. It does not ship the earlier six-point reference or change the completed tomb.

## Bounded method and unchanged behavior

The copied native capture harness uses the current shared simulation and renderer. Before dispatch, it checks **all 528 rope vertices / 176 triangles bit-exactly** against the prior frozen fixture and validates the current authored rope primitive range **3022..3197**. No proxy cylinder, inflated caster or camera-only rope is substituted.

For each of the two actual finite sky-aperture positions, a triangle defines four half-spaces: its plane away from the source and three source/edge planes. Intersecting these cones with the actual finite mist box creates **256 nonempty AABB candidates**. A diagnostic BLAS/TLAS accelerates these bounds. A hardware ray query enumerates candidates along the actual primary camera ray, clipped by the real primary depth and mist segment. It does not confirm broadphase hits, which would prune later intervals. The shader clips each candidate's planes, sorts and unions the intervals, and computes each original density cell's covered length fraction.

Bounds are **512 candidate visits and 64 raw intervals per invocation**. Overflow is explicitly invalid, never silently clear; an actual forced-one-candidate negative capture proves rejection. The numerical cone/bounds implementation is qualified by the tested geometry/rays, not a formal guarantee for arbitrary degenerate or ill-conditioned triangles. Those admission/uncertainty cases need further work before reuse.

Only mist sky queries exclude the verified opaque rope primitive range from the original point-query result and replace its contribution with discovered coverage. Other occluders and RGB transmission retain the existing midpoint policy. Surface queries never enable that exclusion. Staff/fire sources remain independent; the lantern light stays on its physical socket. This is a qualified opaque-rope/sky prototype, **not complete all-material, all-light interval visibility**. The finite-segment helper's near/end epsilon behavior also needs general reconciliation outside this fixture.

The finite aperture positions are `(-34.35, 2.76, -16.02)` and `(-33.05, 2.76, -14.38)`, not parallel moonlight. CURRENT preserves per-pixel aperture parity; HIGHER preserves the existing mist's aperture-zero selection. It does not invent an area-source average. The existing **2/6/8** density locations, density/extinction, attenuation positions, surface shadows, production geometry/masks and quality remain unchanged. Six density cells in this workload are **not six visibility probes**: exact discovered interval overlaps are applied to them.

Extra diagnostic bindings **28/29** and their all-or-nothing roster validation exist solely in copied sources. Production ABI, descriptor enforcement, budgets, packages, shader sources, defaults, tests and gameplay are unchanged. The copied provider identifies its actual measured modules and retains the original module/hash/atomic/entry-point checks.
