# Kit runtime maps

Exact four-map derivative of the owner-approved Meshy Warden source. See
`ASSET_LICENSES.md` and the model runtime README for asset-specific rights and
reproduction commands. This is not a CC0/MIT texture claim.

`texture-receipt.json` pins every compiled payload. Full 1024-square mip chains;
Windows RGBA8, Android ASTC 4x4 normals and ASTC 6x6 base/ORM/emission. Base and
emission use sRGB; normal/ORM use linear data. ORM uses AO=1 because the supplied
source has no AO map. No images were generated, resized down or repainted.

The package policy ships only the four matching platform KTX2 files. Masters,
this receipt and processing inputs are kept outside runtime packages. Chapter
upload appends one family after terrain; the old encoded mips stay identical.
