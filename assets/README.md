# Assets

The showcase alpha uses the Hotstrike Studio skeleton derivative, the CC0 Meshy placeholder lich, five CC0 Poly Haven material sets, seventeen FilmCow WAVs, and project-created branding/icon art. The active development branch also contains audited production Meshy sword, torch, and skinned-player runtime assets; their source/high evidence remains outside release packages. The skeleton was textured, rigged, and animated with Meshy.

Future additions must stay commercial-safe, licensed, bounded, and measured on the Android RT path. Do not expand the shipped audio/model set simply because source assets are available.

Every asset must be recorded in `ASSET_LICENSES.md` before use.
