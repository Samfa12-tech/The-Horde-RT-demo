## Verified native reader constraints

- Binary glTF 2.0, with JSON and BIN chunks. The dedicated skin reader is separate from the generic cgltf static reader. It reads only `meshes[0]` and `skins[0]`; multiple primitives of that first mesh are iterated. Use one mesh and one skin. `SkinnedMeshAsset.cpp:604–645,829–841`.
- Required layout is float32 POSITION/NORMAL/WEIGHTS_0, unsigned-byte JOINTS_0, unsigned-short indices. Four skin influences are read and stored; only JOINTS_0/WEIGHTS_0 participate. UV0 is float32 vec2, tangent is float32 vec4. `SkinnedMeshAsset.cpp:654–725`, source record at `384–392`.
- Joint count is dynamically allocated, with no explicit fixed 24/64/128-joint ceiling in this reader. Its uint8 influence indices can address indices 0–255 only. The E01 gate caps joints at 256 and exported vertices at 65,535; actual uint16 index type is checked. A small rig is a budget choice, not an invented engine joint cap. `SkinnedMeshAsset.cpp:391–392,670,829–841`.
- Weights are copied unchanged. Skinning skips nonpositive/tiny weights or out-of-range joints and does not renormalize. E01 must have four stored influences, finite nonnegative normalized weights, and no positive weight on an invalid joint. `SkinnedMeshAsset.cpp:721–725,1185–1205`.
- Nodes are read as translation/rotation/scale; node `matrix` is not interpreted. Export TRS with mesh/rig transforms baked consistently. Accessor `bufferView` is required. Sparse/compressed/quantized alternatives are not implemented by this reader and are prohibited in the derivative. `SkinnedMeshAsset.cpp:221–258,768–783`.
- Inverse bind matrices must be float32 MAT4, one per skin joint. `SkinnedMeshAsset.cpp:829–841`.
- Animation is limited to four semantic slots: Idle, Walking, Attack, Dead. Bindings are exact-case strings chosen by the caller. Skeleton defaults require `Idle_5`, `Walking`, `Attack`, `Dead`; player defaults require `Idle`, `Walking` only. The new pilot retains Idle/Walking with stable semantic names and Running separately as source-only. It must not be presented as a drop-in skeleton combat replacement. `SkinnedMeshAsset.h:46–65`; `.cpp:419–440,559–570,843–864`.
- TRS channel inputs/outputs must be float32 with equal key counts. Only translation/rotation/scale are accepted. Interpolation metadata is not read; runtime lerps vectors and nlerps quaternions. Bake LINEAR clips; no CUBICSPLINE, STEP semantics or morph channels. `SkinnedMeshAsset.cpp:876–903,1083–1111`.
- Root locomotion must be in-place: gameplay supplies actor x/z/facing in the instance transform, while the skin evaluator retains animated joint translations. There is no extraction/compensation in this route. Measure global root/hips drift rather than assuming provider clips are in-place. `CharacterRenderSlot.cpp:107–124`; `SkinnedMeshAsset.cpp:1109,1171–1177`.
- The current enemy skin route is CPU skinning, upload, then RT BLAS refit. It does not prove GPU skinning. Skeleton uses untextured Skin; lich has a separate textured route. An original PBR source needs a future scoped renderer integration and native validation. `CharacterRenderSlot.cpp:233–246,331–347`.

## Enforced export and QA gates

1. Preserve and hash every original downloaded file. Never overwrite source. Record provider/job/prompt, source licence route, operation and tool version for each derivative.
2. Before a paid rig: inspect actual front/side/back/face/hands geometry at 12K and 6K. Verify separated limbs/fingers, elbow/knee bend regions, tunic clearance, no fused prop/base, facial silhouette and no severe self-intersection. Measure triangles, exported vertices, disconnected components, degenerates, normals, UV coverage and materials. Open clothing boundaries are reviewed, not automatically called watertight failures.
3. Prefer repairing topology/weights over blind decimation. Preserve the more usable source if 6K loses fingers, face or bend loops. Source quality and performance claims remain separate.
4. Runtime-format gate: exactly one mesh and skin; no morph/compression/sparse accessors; <=65,535 exported vertices; uint16 indices; float32 position3/normal3/UV2/tangent4/weight4; uint8 joint4; <=256 joints; four stored nonnegative finite influences summing to 1 within 1e-5; valid index/joint ranges; finite MAT4 inverse binds; TRS nodes; unit-scale asset convention.
5. One material/atlas, 1K maximum runtime maps, PBR base colour + tangent normal + ORM with explicit colour-space metadata. Verify texture links and actual embedded or companion bytes. Preserve original 2K source PBR when present. If rig output loses PBR, restore from exact unchanged source UVs only with measured correspondence.
6. Rig check: rest/bind pose, hierarchy/name manifest, weights, zero-weight count, symmetry plausibility and per-region influence errors. Pose shoulder elevation, elbow 90/120 degrees, wrist rotation, hip stride, knee 90 degrees, ankle and torso twist. Review face/neck/hand/tunic collapse and measure suspect intersections. No facial animation claim without a facial rig.
7. Clip check: exact named Idle and Walking runtime candidates, positive durations, sorted finite times, baked LINEAR TRS, root x/z travel removed in derivative while retaining original source. Keep vertical pelvis motion. Measure loop discontinuity, stance-foot drift/contact, ground penetration and extreme-pose bounds. Running remains in the editable source-only bundle.
8. Fresh Blender import of final GLB, visible pose/deformation evidence and a round-trip import/export/import comparison. Recheck mesh/skin counts, clip/name/counts, accessor formats, weights, texture links and bounds after every export. Preserve editable .blend with packed source images and named actions.
9. A standalone host harness may exercise the actual native SkinnedMeshAsset reader against E01 with explicit pilot clip bindings, without changing engine or repository files. Host importer success is separate from RT material rendering, gameplay, GPU skinning and mobile sustained performance, all NOT RUN in this asset-source task.
10. Deliver source candidate, editable .blend, metrics/validation JSON, provenance/hashes and review sheets. Packages under 18 MB each; no licence-sensitive old skeleton geometry. Do not mark G4/G8/ENG05 native-device gates complete.
