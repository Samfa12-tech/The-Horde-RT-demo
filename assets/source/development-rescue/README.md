# Rescue shaft blockout source

This is an original, development-only Blender blockout for the rescue shaft,
safety cap, upper landing, and coping-anchored rescue-rope frame. The editable Blender file and two GLBs are generated by
`python tools/author-rescue-blockout.py`. The tool reads the shared world metre
bounds in `src/scene/RescueBlockoutGeometry.h`, exports GLB, then imports and
exports the GLB again in Blender before writing `asset.manifest.json` for the
native importer and `source-manifest.json` with byte counts and SHA-256 hashes.
Before launching Blender, the authoring tool verifies that every reused
material source map exists and matches its admitted SHA-256.

The rear posts bear on the rear coping; their crossrail carries one cantilever
whose beam contains the rope anchor at `(-33.7, 3.8, -15.5)`. Its forward end
stays behind the player-root capsule while the hands reach forward to the rope.

The GLBs use opaque PBR materials named for the existing `SurfaceDryStone`
(code 0) and `SurfaceMossyStone` (code 2) world materials. They contain no
textures. The native import test loads the actual second-roundtrip GLB bytes.

Everything in this directory is development source and proof material. It is
outside runtime asset directories and must not be copied into a game package.
