# Flask use: separate source animation candidate

**Unadmitted source study. Production remains OFF.** The editable
`flask-use-study-r1.blend` uses the existing Gothic Traveller body/viewmodel rig,
original sword and the original flask's longer-neck r2 derivative. It preserves
the original bind data and input files, including accepted sword/guard code.
No native binding, GLB clip roster, gameplay state, renderer capacity or save is
changed. This is not a replacement player or animation framework.

The 1.25-second candidate uses the existing 0.30-second Stow and 0.36-second
Restore durations. Lift is 0.30–0.55, the mouth hold 0.55–0.70, flask return
0.70–0.89 and sword restore 0.89–1.25. A second source action cancels at 0.60,
returns the flask over 0.20 seconds and restores the sword over 0.36 seconds.
Those actions author presentation only: no healing, charges or defensive window
is granted here. The brief mouth hold is a brisk swig, not balance acceptance.

The right arm follows a coupled grip/item profile; the left remains at the
original source Idle pose. The body and viewmodel use the same candidate rig.
This does not reproduce the native held-light solve or certify native framing.
Imported display-bone axes/tails are not native joint frames/lengths: the stow
mount reads the raw glTF Hips frame, and reach uses shoulder/elbow/wrist origins.
An outward carry arc avoids the arm's minimum folded reach without stretching
the bind. The mouth target is fitted to the inspected source face; the flask
approaches from the right. Source grip presence is not a skin-contact proof.

`intent.json` records the fixed study timings/targets. `author.py` creates new
source actions and evidence; `review.py` reads the saved actions, checks all
sampled transforms and renders complete/cancel previews. `check-contact.py`
observes four selected source head/contact witnesses; it is not a full swept
collision test or a native acceptance gate.

For a fresh reproducible authoring workspace from the repository root:

```powershell
blender --background --python-exit-code 1 --python assets/models/player/source/flask-use-study-r1/author.py -- --output-directory reports/flask-rebuild-new --editable-output reports/flask-rebuild-new.blend
blender --background --python-exit-code 1 --python assets/models/player/source/flask-use-study-r1/review.py -- --output-directory reports/flask-review-new --motion-receipt reports/flask-rebuild-new/source-motion.json --blend reports/flask-rebuild-new.blend
```
