# Original bounded Bellwether facade refinement

This separately versioned derivative reuses the accepted v2 editable master,
all nine mapped footprints, foundation elevations and two existing native
materials. Runtime has966 triangles (v2 had342), below the unchanged1000-triangle
source limit.52 original closed solid details add door surrounds, tower relief,
closed shutters and frontage footings. There are no interiors, village gameplay,
new lights, flames, transparency, material families or texture layers.

Every frontage footing is surveyed against the preserved actual native terrain
and extends100mm below its lowest sampled support. v3's ungrounded thin step
candidate is preserved but not admitted. v1/v2/v3 sources, exports and backups
are untouched. v2's source and actual terrain hashes plus all facade ray/contact
witnesses are recorded in authoring-receipt.json. Original Horde authoring is
covered by the public chapter task; texture notices remain in ASSET_LICENSES.md.

The exact executed recipe is preserved here. To reproduce, choose fresh versioned
output paths before running Blender5.2 with --python-exit-code1. Backup writing
is disabled and existing directories cause refusal. All held-item, terrain,
collision, material/texture and shader ceilings stay unchanged. Native import,
closed winding/ray witnesses, matched actual RT views and final package checks
must pass before this derivative is called admitted or visually accepted.
