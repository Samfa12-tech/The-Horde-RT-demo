# Bellwether west kitchen plots

Two small beds of leafy greens and leek-like shoots occupy the mapped T02
site at world XZ `(35.3, 136.2)`. The planks, pegs, soil and tool-rest stone
follow the terrain. The 1.32-metre aisle stays on the shared terrain and
connects to the path from the dealer's stall. The 1,872 crop triangles share
the original alder finish. The bed edges and soil add 420 solid town triangles.

Use the [Blender recipe](../../../../../tools/author-bellwether-garden.py) with
the exact town GLB from `fe4e18c1` and a fresh output directory. The
[receipt](authoring-receipt.json) records the parent terrain, geometry and
runtime hashes. The `.blend` contains both the crop and bed meshes.
