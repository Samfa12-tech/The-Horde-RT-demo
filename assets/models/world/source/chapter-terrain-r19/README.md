# Chapter terrain r19: forest-ground derivative

Preserved original Horde Blender master and native GLB derived reproducibly from the r2 topo input. The r18 geometry, topology, support classifications, route, nine occupied-room exclusions and three openings are unchanged. Only material 1 changes from mossy masonry to Poly Haven Forest Ground 01, with UVs at its published 2 m repeat width (0.5 repeats/metre). Trail damp sand remains at 0.42 repeats/metre. Native support classifies both as Earth; historical stone fixtures remain supported.

Run the authoring and validation commands documented in ../chapter-terrain-r18/README.md with a fresh output directory. The updated tools/author-chapter-terrain.py selects the recorded CC0 forest-ground sources. All earlier masters and backups are preserved. authoring-receipt.json records source and output hashes; validation-receipt.json verifies native export correspondence. No geometry simulation or displacement was introduced.

This derivative is copied exactly to runtime/chapter-terrain-v1. The renderer owns uploads/BLAS and publishes the same native triangle surface to the simulation only with generation-checked readiness. Full-body/headroom, completed woodland dressing, Kit, zone retirement and final visual/device acceptance remain open.
