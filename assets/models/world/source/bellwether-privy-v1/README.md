# Bellwether west service yard

The privy is a short detour from the west lane beside the tavern at world XZ
`(77, 112)`. The latched door faces west. The washstand and covered jug sit
beside the step, with a sheltered shelf at hand height. The structure and
its props add 900 solid triangles using the existing town finishes.

The [Blender recipe](../../../../../tools/author-bellwether-privy.py) takes
the town GLB from `3dd8009d` and a fresh output directory. The
[receipt](authoring-receipt.json) records the pinned terrain and town export,
the mouth position behind the door and the exterior hearing point.
