# Bellwether garden-edge grate

An original, dry stone recess with a sheltered bed and a locked iron grate.
Its lip and bars are part of the town collision mesh. The view and talk mark
are on the dry approach from the existing kitchen plots.

The editable Blender master and receipt are here. Rebuild with
`tools/author-bellwether-grate.py` using the exact parent town from commit
`27abeca4` and a fresh output directory. The recipe appends to the existing
town primitives, retaining the same material and primitive counts. It
generates the approach and speech-source coordinates from the same terrain.

The optional staging uses captions. The practical replies and conflicting
stories leave the reason for the lock unresolved.
