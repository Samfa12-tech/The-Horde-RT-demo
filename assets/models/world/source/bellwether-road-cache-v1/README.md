# Bellwether road cache

The split-lid box belongs beside the CHURCH waymarker where the north path
branches from the tavern road. The skids follow the local slope. Its solid
footprint leaves both roads clear and the reach mark sits above the lid.
The box stays in place after the player takes the silver.

The [Blender recipe](../../../../../tools/author-bellwether-road-cache.py)
uses the pinned town GLB from commit `9969bd75` and a fresh output directory.
The [receipt](authoring-receipt.json) records the editable source, merged
runtime GLB, manifest and interaction marks. The box adds 168 solid triangles
to the existing timber and char primitives without new textures.
