# Grave markers r03

Two original closed, bevelled stone forms. Native metre scale, +Y up/+Z forward. Editable master and reproducible authoring remain outside runtime packages. Plain markers reveal no new lore. Nonemissive; no new lights or textures. Derivation receipt binds the master, script and exports.

Reproduce into a NEW revision with `blender --background --factory-startup --python tools/author-grave-markers.py -- --revision rNN`. Existing revision directories are refused and Blender backup writes are disabled before saving. Final native admission and RT inspection are separate gates.
