# Clustered crown r3 — unadmitted source study

This original owned derivative replaces only foliage with closed3D lobe meshes,
not scaled leaf lenses. Original trunk/roots/branches, moss, packed images and
materials remain byte-identical.147 pine lobes and132 alder lobes use the exact
existing5,000/5,102 triangle budgets, three materials and unchanged manifest.
Used vertices decrease to3,700/3,916; this is not a measured performance gain.

The study is **rejected as a blanket near-tree replacement**. Native RT proves
more canopy silhouette volume, but coarse nearby lobes and open eye-level land
still fail the woodland goal. The ordinary moving-route restoration gate fails.
See the [inspected comparison and limitations](../../../../../docs/evidence/2026-10-26-forest-crown-clusters-r3/README.md).

Reproduce in a fresh ignored destination from this worktree:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' -b --threads 2 --python assets/models/world/source/forest-crown-clusters-r3/build.py -- --output reports/<fresh-study>/candidate/assets
```

The builder creates finite closed icosahedral/octahedral lobe meshes with positive
volume and oppositely paired edges, retains the other GLB buffer views, and
repacks aligned buffers. Source originals are read only. This does not invoke
Blender's glTF exporter, access its denied temporary-image directory, or change
permissions. It uses the installed Blender/numpy runtime; no dependency install,
paid generation or external source asset. Rights remain those of the owner-
authored tree pair recorded in `forest-tree-pair-v1` and `ASSET_LICENSES.md`.

The initial UV tangent direction was corrected to the analytic increasing-U
derivative. Position/index/normal/UV/image streams stay byte-identical; a fresh
native north import/recreation passes and its PNG is bit-identical. The retained
patch and hashes distinguish initial moving-route evidence from the final recipe.
No complete final-candidate route pass is claimed.

Raw GLBs, editable Blender comparison, lossless PNGs/CSV/OBJ files and complete
receipts remain under `reports/forest-crown-clusters-r3-20261026/`. No trial master
is placed in runtime packages. The `game-dev` CLI is unavailable; this is not a
verified canonical package or shipping-ready asset. Preserve original production
trees and all rejected evidence.
