# Bellwether mill tally props

The dry turnout's banded case holds the stamp. A separate tray on the west
stall counter distinguishes named trade from ordinary Silver. The ownership
board sits beside the mill's registered west doorway.

Rebuild with Blender 5.2 in background mode and
`tools/author-bellwether-tally.py`, passing the repository root, town GLB from
commit `05cbdec8`, and a fresh output directory after the argument separator.
The recipe appends the props to the current town geometry and writes the
exact interaction marks to the generated header. It preserves the town's
material and primitive counts.
