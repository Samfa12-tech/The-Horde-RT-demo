# Prepared original woodland rocks

The three original supplied rock masters are preserved in
`../forest-understory-v1/original-package/`, including its editable Blender
scene, original-authorship statement, maps, scripts and hash manifest.
`tangent-recipe.executed.py` is the existing Blender derivative workflow.
Run it with a new output path using `--python-exit-code 1`; never overwrite
an existing derivative or master. Per-asset receipts prove triangles, winding,
UV0 and normals survive, and embedded image pixels remain identical.

Runtime admission uses the existing Boulder01Rock PBR family. This is a
documented reversible material selection: original slate maps remain preserved,
while the chapter shares its existing measured stone textures. Twelve uneven
rocks sit outside the clear trail. Their basis follows the native terrain normal;
the bottom perimeter is surveyed against that terrain and buried by 30mm.
Their exact world triangles also extend the immutable nonwalkable contact owner
without replacing ground, tree root heights or existing graveyard contact.
Source scale and triangle counts are retained; no decimation or new feature.

Only the three selected GLBs and the bounded manifest enter runtime packages.
Tangent receipts, editable originals and this source record stay outside them.
