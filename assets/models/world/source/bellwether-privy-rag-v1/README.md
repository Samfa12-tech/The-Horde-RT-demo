# Bellwether clean rag

The clean-rag basket sits on a timber stand beside the west-facing privy.
The folded linen starts in the basket and appears on the sheltered shelf after
delivery. One rigid ray-traced prop uses both marks. The linen has 56 triangles
and an untextured opaque material. The basket and stand add 248 solid triangles
to the existing town materials.

The [Blender recipe](../../../../../tools/author-bellwether-privy-rag.py) takes
the town GLB from `eef05d29` and a fresh output directory. The
[receipt](authoring-receipt.json) records both placement marks and the exact
cloth and town export hashes.
